# Replay Tático

- Trabalhe apenas neste repositório. O TaquaruçuVision é um projeto independente.
- Use `tp2.pdf` como fonte prioritária. O dossiê local registra o contexto e o planejamento.
- Conte quadros a partir de zero e preserve o índice no vídeo de origem em todo o pipeline.
- Use o trecho de ajuste para escolher parâmetros. Congele a configuração e obtenha a anotação manual do grupo antes de executar qualquer inferência no trecho de avaliação.
- Use as anotações manuais de avaliação apenas na comparação posterior. Registre perdas e resultados inconclusivos.
- Execute os testes com `python -m unittest discover -s tests -v` e atualize `docs/STATUS.md` a cada etapa testada.
- Envie commits testados à branch `main` de `Lucas04zx/ReplayTatico`. Solicite autorização explícita antes de tornar o repositório público ou compartilhar acesso.
- Mantenha credenciais, pesos, vídeos e resultados locais fora do Git. Confira direitos antes de distribuir material de terceiros.
